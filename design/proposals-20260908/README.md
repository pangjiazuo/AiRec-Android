## 共同操作约定

- 手机底部保留实时、回放、事件、设置四个入口。
- 点击任意通道进入详情：上方画面预览，下方仅显示该通道的回放或事件；右上角齿轮进入本通道设置。全屏由预览内按钮显式进入。
- 四类事件：长时间停留、人、车、动物。红、蓝、紫、绿小圆点配文字；圆点在截图下方，卡片没有彩色外框。人和动物才进行停留检测。
- 无信号通道有独立状态，仍可进入历史和通道设置；断网显示重连状态。
- 全局设置仅显示设备连接、录像存储、识别模型、日志与诊断四类入口。通道配置不回到全局设置；应用到其他通道保留在通道设置里。
- 设备温度、CPU、内存和存储以紧凑摘要显示，点入查看详细设备状态。
- 时间轴显示已完成录像的区间与缺口，未封装片段不能假装可回放。点事件可以查看截图及可用的关联录像。
- 不加入当前没有支持的云台、对讲、云录像、警笛或云服务按钮。

## 平板和横屏的适配方向

这轮主图用于比较手机视觉，尚不是每个尺寸的最终施工稿。选定后补充适配细节：A 扩展为主通道＋辅通道网格，B 扩展为三列视频墙，C 扩展为通道列表与内容分栏。通道详情在宽屏采用左预览、右回放/事件；侧边导航替代底栏，保留当前通道、筛选和播放位置。不会简单放大手机界面。
