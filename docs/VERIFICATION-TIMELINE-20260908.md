## 功能范围

全局回放移除顶部时间轴，保留片段列表与下载。通道详情移除录像列表和下载入口，使用完整日索引、垂直时间轴与上方原位回放，支持日期选择、概览/精细尺度和返回实时。四类事件分别使用红、蓝、紫、绿标记；空白保留真实录像缺口，相接或重叠片段才能续播。

时间轴的“选中时刻”保留秒级精度，播放器进度条显示实际播放进度。拖动、缩放和中断不会留下永久暂停状态；旋转保留定位、暂停意图和页面上下文。原生 Media3 播放范围限制在所选自然日内，跨午夜片段的进度条也不能进入前后一天。

完整索引来自新增 `/api/timeline`，不再用最近 200 条推断全天。接口支持真实时区、跨午夜、23/25 小时日期、缺失文件与显式错误。API 文档已与 Ubuntu 源文档同步。

## 原生与真实数据验证

仅使用本任务创建的只读 `Medium_Phone` 模拟器，目标 `emulator-5556`，Android 13 / API 33。没有对用户手机安装软件或操作其他模拟器。

- 本轮隔离业务回归覆盖五路独立状态、通道设置作用域与批量应用、筛选/日期/横竖屏恢复、主题、断网恢复、设置草稿。初轮 13 个业务用例中 12 个通过，发现底部导航遮挡保存按钮后改为根布局预留导航高度；最终版重跑该用例通过。
- 最终版时间轴交互检查通过重复选时、精确 00:00:08 在缩放与恢复后保持、拖动中禁用/缩放取消、同 URL 重复定位四项；另加重跑通过的设置页用例，证据为 `timeline-interactions-delivery.txt` 中对应五项成功结果。
- 原生跨午夜播放测试最终通过，26.557 秒，见 `native-clipping-verified.txt`：90 秒媒体限定原文件 30～60 秒，原生时长为 30 秒，原文件 37 秒对应裁剪后 7 秒，原生起点可定位，播放末尾自然进入 ENDED 且完成回调只有一次。结束位置经应用范围转换后严格封顶原文件 60 秒，播放器停止推进。
- 原生测试经历了测试脚本修正：Mock URL 移到仪器线程；暂停态定位末点改为播放最后 250 毫秒等待自然结束；不再要求 ENDED 后的原始音频时钟精确等于时长（实际曾上报 30276 毫秒），改验应用保存的位置封顶、原生裁剪时长和单次结束。只改测试，不以修改产品行为迎合断言。测试 APK 后续为单独增量构建，交付应用 APK 摘要始终未变。

- 两次真实回放都验证完整日加载、上方 Media3 实际播放、对应片段偏移、重复定位、暂停后旋转、位置与暂停意图恢复、全屏退出、返回实时、详情无下载/全局导航、全局列表无旧时间轴、事件与设置可进入。

API 31 的最低要求已由最终 APK 元数据核实；本轮实际运行系统为 API 33，没有将其表述为 Android 12 真机测试。没有五路物理摄像头同时在线的数据，未重新声称五路实机帧率或长时间稳定性通过。真实板端操作仅限读取既有录像与索引。完整日大容量和跨午夜模型边界已使用隔离数据验证；原生裁剪采用可重复生成的静音 WAV 检查时长、偏移与完成状态，真实 MP4 的解码与定位由板端回放用例覆盖，不据此宣称所有音视频格式均达到帧级剪辑精度。
