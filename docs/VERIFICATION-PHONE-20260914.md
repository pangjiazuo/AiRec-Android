# 手机界面核对 · 1.5.1

2026-09-14，以用户提供的 AiRec-mobile-design 为参照，在 API 33 手机模拟器运行实际 APK 后截图。

## 核对范围

49 个页面及状态，每页有浅色与深色运行图，包括主页面、通道详情、二级设置、选择面板、回放、下载和错误状态。修正了旧版的页面结构、按钮位置、横屏全屏、日期确认按钮遮挡及许可文本直接铺开的问题。

原稿的手机深色参考只有首页、通道详情和设置三张。其他深色页面沿用相同配色，其结构与对应浅色原稿对照，没有把新生成的图冒充已确认设计。

## 截图怎么产生

- 正常页面：实际 APK + 手机模拟器 + 隔离测试服务。
- 下载及播放器辅助图：真实界面组件，用测试状态验证加载、完成、失败及按钮；不能单凭这些图片认定视频解码或文件保存成功。
- 截图使用无人物画面。README 只展示实时、回放列表与设置，不放事件页面。
- 系统状态栏、原生日期和文件选择器、真实名称与容量不固定成设计示例值。复制参数仍先进入草稿，明确保存后才写入设备。

## 测试结论

47 项单元测试、Lint、页面及时间轴回归已执行；最终浅色与深色各 5 项页面和重连测试通过。实际板卡全天回放最新一次通过，但本轮曾有间歇性索引加载超时，不能当成长期稳定性验收。当前仅接 AHD1，未验证五路实拍。
